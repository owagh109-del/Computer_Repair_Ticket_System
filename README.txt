# Computer Repair Ticket System

PHP + MySQL + HTML + CSS DBMS Unit 4 project.

## Files

- index.php - main PHP application
- style.css - external CSS
- database.sql - MySQL database and sample data

## XAMPP Setup

1. Copy the `Computer_Repair_Ticket_System` folder to:
   `C:\xampp\htdocs\`

2. Start Apache and MySQL from XAMPP Control Panel.

3. Open:
   `http://localhost/Computer_Repair_Ticket_System/`

The PHP application automatically creates the database and table.

## Manual Database Setup

You can also import `database.sql` using phpMyAdmin.

Database name:
`computer_repair_db`

Table:
`repair_tickets`

Default XAMPP MySQL credentials used by index.php:
Host: localhost
User: root
Password: empty
